# 小企鹅输入法·DSHA修改版

基于 [fcitx5-android](https://github.com/fcitx5-android/fcitx5-android)（小企鹅输入法）的个人魔改版，
只调整**输入体验的细节**，不加键位行、不改打字逻辑、不改主题默认配色。

> 当前版本：**1.0.0**（发布日期见 Releases）

---

## 使用体验改了什么

| # | 位置 | 改后 |
|---|---|---|
| 1 | **空格键（长按）** | 支持长按空格对外部联动 AIDL，可进行语音输入（需安装其它应用） |
| 2 | **第四行颜文字键位** | `:-)` 一键打开颜文字面板 |
| 3 | **`?123`** | 单击进入数字键盘，长按/上划进入符号键盘 |
| 4 | **`，。` 合一键** | 点 = 逗号，上划 / 长按 = 句号，键面带句号角标（角标位置遵循「主题 → 标点位置」） |
| 5 | **候选栏** | 双击清空预输入 |
| 6 | **语言键（长按）** | 弹出系统输入法选择器 |
| 7 | **卸载重装** | 首次启动自动从备份恢复配置与词库 |

实现位置与注意事项见 [`docs/MODS.md`](docs/MODS.md)。

## 🛡️ 安全使用须知

1. **先备份再替换**：安装兼容版前，先把配置/词库备份到 `Download/fcitx-backup`
   （恢复来源为 `Android/media/<包名>/backup`，详见安装说明），并保留官方版 APK 以便回退。
2. **只使用本仓库的安装包**：核对 Releases 中的 `SHA256SUMS.txt`。
3. **敏感输入请切回官方版或系统输入法**：本包未经审计，密码、支付、证件号等场景请使用可信输入法。
4. **语音内容会离开本机**：仅在信任所装语音应用时使用，不要在语音中输入敏感信息。
5. **备份目录含个人词库**：`Android/media/<包名>/backup` 与 `Download/fcitx-backup` 属于个人数据，请勿随意分享。
6. **不要授予多余权限**：本包不需要网络能力。
7. **升级是手动的**：先备份再覆盖安装。
8. **卸载前先切换输入法**：先把默认输入法切回系统输入法，再卸载，避免出现没有可用键盘的情况。
9. **系统提示签名不一致时**：先核对 sha256 确认是本项目发布包，否则停止安装。

## 权限与隐私

- 需要 `RECORD_AUDIO`（语音输入）、输入法绑定权限等运行所需权限；
- **不申请 `INTERNET` 权限**，没有联网、统计、遥测逻辑；
- 词库、配置、主题均保存在本地；输入内容不离开设备（语音除外，见安全声明）。

---

## 安装与回退

1. 从 Releases 下载对应版本（`兼容版` 或 `独立版`）；
2. 允许从文件管理器安装本 APK（系统可能提示"未知来源"）；
3. **兼容版**：会替换官方版，请先备份；
   **独立版**：可与官方版共存；
4. 打开输入法管理，启用「小企鹅输入法·DSHA修改版」，并设为默认输入法；
5. 回退：卸载本版后重新安装官方版；或直接用官方 APK 覆盖（签名不同，需先卸载）。

词库/配置恢复来源（按顺序尝试）：

```
/sdcard/Android/media/org.fcitx.fcitx5.android/backup   （兼容版）
/sdcard/Android/media/com.dsha.xiaoqie.ime/backup       （独立版）
/sdcard/Download/fcitx-backup
```

> 卸载会清空应用私有数据；`Download/fcitx-backup` 不受影响。

## 已知限制

- 官方更新器不可用（签名不同）；
- 依赖签名级权限的插件（如 clipboard-filter）不可用；
- 部分 ROM（如 MIUI）会过滤第三方应用 logcat，排障受影响；
- 独立版因包名不同，插件与官方数据的兼容性不保证。
